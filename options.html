Only used when "Include images when scoring" is on. If set, images are read locally by this vision model first, and the extracted text is merged into the post before scoring — your main model above never needs vision support. Leave blank to send images to the main model directly instead (it must support vision itself). A small general vision model like lmstudio-community/Qwen2-VL-2B-Instruct-GGUF is a light, RAM-friendly choice that handles both text-in-image and photos/memes; allenai/olmOCR-2-7B-1025 is a heavier, document-OCR-specialized alternative (gets a different, more structured prompt automatically since its id contains "olmocr").

Sends each post's own photo or video thumbnail to the model along with its text. Off by default — images add cost and latency to every scan. With Local (LM Studio), only works if the loaded model actually supports vision (e.g. Qwen2-VL, LLaVA); a text-only model will error or ignore images.

Post-detection depends on X's internal page structure, which can change without notice. When on (recommended), the panel shows a warning if scans keep finding zero posts instead of silently doing nothing — nothing else about how the extension behaves changes.

Reply Scout never posts, likes, or follows for you. It scores and drafts; you decide.
